# PETI

## Objetivos de Negócio

- Reduzir o tempo perdido com solicitações de TI não organizadas dentro de uma empresa fictícia de médio porte.
- Otimizar o atendimento aos funcionários da empresa.
- Manter um histórico de solicitações de funcionalidades.
- Reduzir o impacto financeiro.

## Objetivos de TI

- Oferecer um sistema simples de abertura e acompanhamento de chamados, acessível a todos os setores.
- Interface intuitiva e funcional.
- Sistema com processamento rápido.
- Desenvolvimento de uma aplicação de fácil acesso a todos os funcionários, exemplo: Site Web com banco relacional.

## Indicador de Sucesso

- Reduzir de "sem controle" para 100% dos chamados registrados e rastreáveis até o fim do semestre.
- Organização dos chamados e redução de conflitos.
- Satisfação sobre a qualidade do serviço.
- Taxa de adesão do sistema.
- Redução de custos.

## Prioriedade da Semana

- Atribuir as tarefas para cada integrante no Trello.
- Criar o Front-End da tela de chamados.
- Implementar o cadastro real de chamados.
- Criar o banco de dados para persistência dos dados.
- Realizar o versionamento do código.
- Realizar testes no sistema.
